# AVL tree (persistent)

## Intent
An AVL tree is a binary search tree that keeps itself balanced: at every node the heights of the two subtrees differ by at most one. After an insert or delete, one single or double rotation on the way back up the path restores that rule, so the height stays below 1.44 log2(n + 2) and every operation is O(log n) in the worst case.

## Use when / avoid when
- Use it for an ordered set where lookups dominate: the rule is stricter than the red-black rule, so the tree is slightly shallower.
- Use it to learn rotations with an invariant you can check by a law.
- Avoid it when you need a map with values: `rb_tree` has `RbMap`.
- Avoid it when order is not needed: `hamt` or `hash_table` look up in O(1) expected.
- Avoid the unbalanced `bst` for anything whose input order you do not control.

## Nim shape
`AvlTree[T]` is a value with a `ref` root and a size. Each immutable node stores its item, its height and two children. `balance(x, l, r)` builds a node from an item and two subtrees whose heights differ by at most two (what one update can cause) and rotates when they differ by two: a single rotation when the taller side leans outward, a double rotation when it leans inward. Items need `<`.

```nim
import nimcs/ds/avl_tree

let t = fromSeq([1, 2, 3, 4, 5, 6, 7])           # sorted input would make a plain BST a list
doAssert t.height == 3
doAssert t.toSeq == @[1, 2, 3, 4, 5, 6, 7]
doAssert t.invariantsHold
let d = t.delete(4)
doAssert d.toSeq == @[1, 2, 3, 5, 6, 7] and d.invariantsHold
doAssert t.contains(4)                           # t is unchanged
```

`invariantsHold` checks search order, stored heights and the balance rule at every node. A property test can call it after each step:

```nim
import nimcs/ds/avl_tree

var t = emptyAvl[int]()
for i in 0 ..< 200:
  t = t.insert(i * 37 mod 101)
  doAssert t.invariantsHold
for i in 0 ..< 100:
  t = t.delete(i)
  doAssert t.invariantsHold
doAssert t.height <= 8
```

tests fail when it drifts). `import nimcs/ds/avl_tree` brings these names. A type they use from
another module (`Option`, `Result`, `Graph`) needs that module's import too, as in the example
above. A field marked `*` is readable outside the module; a type shown without fields is opaque,
built and read only through the functions.


## Laws and invariants
- Inserted items come out of `toSeq` sorted and distinct, `len` counts them, and the AVL invariant holds (DS-AVLTREE-01).
- `contains` is true exactly for the inserted items (DS-AVLTREE-02).
- The balance invariant (subtree heights differ by at most one, stored heights correct, search order) holds after every insert and delete (DS-AVLTREE-03).
- `delete` removes the item and keeps the rest (DS-AVLTREE-04).
- Sorted and reverse-sorted inserts keep the height logarithmic (DS-AVLTREE-05).
- The four shapes that need a rotation (left-left, right-right, left-right, right-left) each end with height 2 and sorted contents (DS-AVLTREE-06).
- Updates leave the old tree unchanged (DS-AVLTREE-07).
- The empty tree has no smallest item and `delete` keeps it empty (DS-AVLTREE-08).

## Complexity
| Operation | Time | Space |
|---|---|---|
| `contains` | O(log n) | O(1) |
| `insert`, `delete` | O(log n) worst case | O(log n) new nodes |
| `smallest`, `height`, `len` | O(log n), O(1), O(1) | O(1) |
| `toSeq`, `fromSeq` of n items | O(n), O(n log n) | O(n) |

## Pitfalls
Updating the stored height before the children are final, or rotating without recomputing the heights of the nodes the rotation moved, leaves a tree that looks sorted but whose balance test is wrong.

```nim bad
type Node = ref object
  elem, height: int
  left, right: Node

func rotateRight(n: Node): Node =
  let l = n.left
  n.left = l.right                     # mutates a shared node and keeps stale heights
  l.right = n
  l
```

Build new nodes with a constructor that computes the height from its children (`mk`), and test the invariant after each step.

```nim
import nimcs/ds/avl_tree

let t = fromSeq([3, 2, 1])             # the left-left case: one right rotation
doAssert t.height == 2 and t.invariantsHold
```
