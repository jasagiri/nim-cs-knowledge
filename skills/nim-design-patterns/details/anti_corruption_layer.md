# Anti-corruption layer

## Intent
Translate a foreign model at the border so it never leaks inward. Another system's model has its own words, codes and number formats, and it changes when its owners decide. The layer is the only place that knows both models. It turns a foreign record into your own type through the same smart constructor as every order of your own, and turns it back when you must send one. Your code takes your type and cannot be handed a foreign record.

## Use when / avoid when
- Use when a model you do not control meets one you do: a supplier's message format, a legacy database, a partner's API.
- Use when the foreign model changes or comes in several versions: each version is one more pair of functions and nothing inward moves.
- Avoid between two parts of your own model: translation there hides a design that should be shared.
- Avoid when the foreign model is the one you want; then adopt it openly and say so, rather than wrapping it.

## Nim shape
`src/nimcs/patterns/anti_corruption_layer.nim`. The inner model is `Order` (a non-empty id, a status enum, a non-negative `Cents`). `initOrder` is the one place its invariants are checked. The supplier's records are `ForeignOrderV1` (a status letter, an amount as text) and `ForeignOrderV2` (status words, integer cents). `fromV1` and `fromV2` translate, each refusing with a specific `TranslateError`; `toV1` and `toV2` go back. `canShip` is an inner rule and takes only `Order`. `translateAll` translates a batch and lists each refusal with its index.

```nim
import nimcs/patterns/anti_corruption_layer

let v1 = ForeignOrderV1(reference: "A-7", statusCode: "A", amount: "12.50")
let order = fromV1(v1)
doAssert order.isOk and order.value.total == Cents(1250)
doAssert canShip(order.value)

# The second supplier format gives the same inner order.
doAssert fromV2(toV2(order.value)) == order

# A bad record is a value with a reason, not a zero.
doAssert fromV1(ForeignOrderV1(reference: "A-8", statusCode: "?", amount: "1.00")).error == teUnknownStatus
let batch = translateAll(@[v1, ForeignOrderV1(reference: "", statusCode: "A", amount: "1.00")], fromV1)
doAssert batch.orders.len == 1 and batch.refused == @[(index: 1, error: teEmptyId)]
```

## Public API

Every exported symbol of `src/nimcs/patterns/anti_corruption_layer.nim`, generated by `nim apiSections` (the
tests fail when it drifts). `import nimcs/patterns/anti_corruption_layer` brings these names. A type they use from
another module (`Option`, `Result`, `Graph`) needs that module's import too, as in the example
above. A field marked `*` is readable outside the module; a type shown without fields is opaque,
built and read only through the functions.

```text
type OrderStatus = enum
  osActive, osShipped, osCancelled
type Cents = distinct int
type Order = object
  id*: string
  status*: OrderStatus
  total*: Cents
type TranslateError = enum
  teEmptyId, teUnknownStatus, teBadAmount
type ForeignOrderV1 = object
  reference*: string
  statusCode*: string
  amount*: string
type ForeignOrderV2 = object
  orderId*: string
  state*: string
  minorUnits*: int
type Refusal = tuple[index: int, error: TranslateError]
type Translated = tuple[orders: seq[Order], refused: seq[Refusal]]
func `==`(a, b: Cents): bool
func `<`(a, b: Cents): bool
func `$`(c: Cents): string
func initOrder(id: string; status: OrderStatus; total: int): Result[Order, TranslateError]
func canShip(o: Order): bool
func fromV1(f: ForeignOrderV1): Result[Order, TranslateError]
func fromV2(f: ForeignOrderV2): Result[Order, TranslateError]
func toV1(o: Order): ForeignOrderV1
func toV2(o: Order): ForeignOrderV2
func translateAll[F](xs: seq[F]; translate: proc (f: F): Result[Order, TranslateError] {.noSideEffect, raises: [].}): Translated
```

## Laws and invariants
Why this is testable: each translation is a function from a record to a `Result`, so "no change of theirs reaches us" is an equation between orders, and "no foreign type reaches inward" is a compile check.
- Sending an inner order out in either supplier format and translating it back gives the same order, and the two formats agree (PAT-ANTICORRUPTIONLAYER-01).
- A foreign record is either refused with a specific reason or becomes an order with a non-empty id and a non-negative total (PAT-ANTICORRUPTIONLAYER-02).
- An inner operation does not compile when handed a foreign record (PAT-ANTICORRUPTIONLAYER-03).
- A batch keeps the accepted orders in order and lists each refusal with its index (PAT-ANTICORRUPTIONLAYER-04).

## Complexity
Each translation is O(length of the record). `translateAll` is O(batch size) and keeps the refusals in memory.

## Pitfalls
Letting the foreign type travel one function further "just for now" ties the inner code to the supplier's next release.

```nim bad
func canShip(o: ForeignOrderV1): bool =
  o.statusCode == "A" and o.amount != "0.00"   # their codes and text amounts are now ours
```

Translate once at the border and keep the rule on the inner type:

```nim
import nimcs/patterns/anti_corruption_layer

let o = fromV1(ForeignOrderV1(reference: "A-7", statusCode: "A", amount: "0.00"))
doAssert o.isOk and not canShip(o.value)
```

Do not default on a refusal (an unknown status as "active", a bad amount as 0): the layer exists so that a foreign mistake stops at the border with a name.
