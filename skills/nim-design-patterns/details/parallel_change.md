# Parallel change (expand and contract)

## Intent
Change something many callers depend on (a stored field, a function's arguments, a message format) in three steps that each leave every caller working. Expand: the new shape exists next to the old one and every writer keeps both in step. Migrate: rows written before the change are filled in and callers move one at a time. Contract: the old shape is removed once nothing reads it. The module moves a person's name from one legacy text, "Family, Given", to a `Name` of two parts.

## Use when / avoid when
- Use when callers cannot all change in one commit or one deploy: a database column, a public function, a wire format read by clients you do not release together.
- Use when a step must be reversible: until contract, going back is just stopping.
- Avoid when one commit can change the definition and every caller together (a private helper): a rename is cheaper than three steps.
- It costs a period in which two shapes exist. Give the period an end, or contract never happens.

## Nim shape
`src/nimcs/patterns/parallel_change.nim`. A `Record` holds both columns as `Option`s. `writeCurrent` and `writeLegacy` are the two doors; each sets both columns, and the legacy door refuses a text it cannot translate instead of storing something only one reader can use. `readCurrent` and `readLegacy` use their own column and otherwise translate the other. `backfill` fills rows from before the change. `contract` is a function from the store to a store without the legacy column, and it refuses while some row would lose its only copy.

```nim
import std/options
import nimcs/patterns/parallel_change

let ada = writeLegacy("Lovelace, Ada")
doAssert ada.isOk
let grace = writeCurrent(initName("Grace", "Hopper").value)
doAssert ada.value.readCurrent == some(initName("Ada", "Lovelace").value)
doAssert grace.readLegacy == some("Hopper, Grace")

# A row from before the change has only the legacy text.
let alan = Record(legacy: some("Turing, Alan"), current: none(Name))
let refused = contract(@[grace, alan])
doAssert refused.isErr and refused.error.firstUnmigrated == 1

let done = contract(@[grace, alan.backfill])
doAssert done.isOk and done.value[1].legacy.isNone
doAssert done.value[1].readCurrent == alan.readCurrent
```

## Public API

Every exported symbol of `src/nimcs/patterns/parallel_change.nim`, generated by `nim apiSections` (the
tests fail when it drifts). `import nimcs/patterns/parallel_change` brings these names. A type they use from
another module (`Option`, `Result`, `Graph`) needs that module's import too, as in the example
above. A field marked `*` is readable outside the module; a type shown without fields is opaque,
built and read only through the functions.

```text
type NameError = enum
  neEmptyGiven, neEmptyFamily, neComma, neNoSeparator
type Name = object
  given*, family*: string
type Record = object
  legacy*: Option[string]
  current*: Option[Name]
type Store = seq[Record]
type ContractError = object
  firstUnmigrated*: int      ## index of the first row with no current name
func initName(given, family: string): Result[Name, NameError]
func formatLegacy(n: Name): string
func parseLegacy(s: string): Result[Name, NameError]
func writeCurrent(n: Name): Record
func writeLegacy(s: string): Result[Record, NameError]
func readCurrent(r: Record): Option[Name]
func readLegacy(r: Record): Option[string]
func backfill(r: Record): Record
func contract(s: Store): Result[Store, ContractError]
```

## Laws and invariants
Why this is testable: the readers, writers, `backfill` and `contract` are functions of values, so "both callers agree" and "nothing is lost" are equations between return values.
- Whichever door wrote a record, the legacy reader and the current reader agree (PAT-PARALLELCHANGE-01).
- A row that holds only the legacy text reads the same through both readers, and a text that does not parse reads as no current name (PAT-PARALLELCHANGE-02).
- `backfill` is idempotent, changes no reader's answer, and gives every parsable row a current name (PAT-PARALLELCHANGE-03).
- `contract` is refused at the first row without a current name; after `backfill` it succeeds and every current answer is kept (PAT-PARALLELCHANGE-04).
- A name survives the legacy text: `parseLegacy(formatLegacy(n))` is `n`, and the constructor rejects the parts for which it would not be (PAT-PARALLELCHANGE-05).

## Complexity
Each read and write is O(length of the text). `backfill` and `contract` are O(rows). The storage cost of the expand period is both columns for every row.

## Pitfalls
The common mistake is to start with the part that cannot be undone, or to let one door write only its own column. Then the other reader sees nothing, and the problem shows up in production, not in the type checker.

```nim bad
func writeCurrent(n: Name): Record =
  Record(legacy: none(string), current: some(n))   # an old caller now reads nothing
```

Write both columns in both doors, and make the legacy door refuse what it cannot translate:

```nim
import std/options
import nimcs/patterns/parallel_change

let r = writeCurrent(initName("Ada", "Lovelace").value)
doAssert r.readLegacy == some("Lovelace, Ada")
doAssert writeLegacy("no separator").isErr
```

Also do not contract on a calendar date: contract when `contract` accepts the store and the callers of the old reader are gone.
