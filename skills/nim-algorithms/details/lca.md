# Lowest common ancestor (binary lifting)

## Intent
In a rooted tree, the lowest common ancestor of two vertices is the deepest vertex that is an ancestor of both. Binary lifting stores the 2^k-th ancestor of every vertex for every k, so any ancestor is reached by the set bits of the distance, and a query lifts the deeper vertex to the other's depth and then both together while their ancestors differ.

## Use when / avoid when
- Use it when the tree is fixed and many queries follow: distances between vertices, path queries, network or organisation hierarchies.
- Walk up the parent array for a single query; it is simpler and needs no preprocessing.
- Use an Euler tour with a sparse table when O(1) queries matter more than the simplicity of lifting.

## Nim shape
`buildLca(parent)` takes a parent array (`-1` for the single root) and returns `Result[LcaTree, LcaError]`; it rejects an empty array, a parent out of range, no root or several roots, and a cycle among parents. Queries return `Option`: `lca(u, v)`, `depth(v)`, `kthAncestor(v, k)`, `distance(u, v)` are none for a vertex outside the tree. Module: `src/nimcs/algo/lca.nim`.

```nim
import std/options
import nimcs/fp/result
import nimcs/algo/lca

#        0
#       / \
#      1   2
#     / \   \
#    3   4   5
let built = buildLca(@[-1, 0, 0, 1, 1, 2])
doAssert built.isOk
let t = built.value
doAssert t.lca(3, 4) == some(1)
doAssert t.lca(3, 5) == some(0)
doAssert t.distance(3, 5) == some(4)
doAssert t.kthAncestor(3, 2) == some(0)
```

## Laws and invariants
- `lca` equals the walk-up oracle on every pair of every generated tree (LCA-QUERY-01).
- `lca` is symmetric, `lca(u, u) = u`, the root with anything is the root, a parent with its child is the parent (LCA-QUERY-02).
- `depth` is the number of steps to the root (LCA-DEPTH-01).
- `kthAncestor` equals k single steps and is none past the root (LCA-ANCESTOR-01).
- `distance(u, v) = depth(u) + depth(v) - 2 depth(lca(u, v))` (LCA-DISTANCE-01).
- Every kind of malformed parent array has its own error (LCA-BUILD-01).
- A vertex outside the tree is answered with none (LCA-BUILD-02).
- A root other than vertex 0, and parents with larger indices than their children, are handled (LCA-BUILD-03).

## Complexity
Preprocessing O(n log n) time and space (a table of ceil(log2 n) levels). Each query O(log n). Building from a parent array needs one breadth-first pass for the depths; it does not assume parents have smaller indices.

## Pitfalls
Computing depths in index order assumes every parent has a smaller index than its child, which a parent array does not promise:

```nim bad
for v in 0 ..< n:
  depth[v] = depth[parent[v]] + 1     # parent[v] may not be computed yet
```

Fix: walk from the root in breadth-first order (children before grandchildren), as `buildLca` does; the same pass shows a cycle, because a vertex that cannot reach the root is never visited. Another trap is lifting the two vertices together before they are at the same depth.
