# Aho-Corasick multi-pattern search

## Intent
Find every occurrence of every pattern of a fixed set in a text with one left-to-right pass. The patterns are merged into a trie, each trie node gets a failure link to the node of its longest proper suffix that is also in the trie, and the links are folded into a complete transition table so the scan never backs up.

## Use when / avoid when
- Use it when many patterns are searched in the same text or stream: word filters, signature scans, keyword tagging.
- Use `kmp.md` for a single pattern, `rabin_karp.md` for many patterns of one length, `suffix_array.md` when the text is fixed and the patterns change.
- Avoid it when the pattern set changes after every search: the automaton is built once and is immutable.

## Nim shape
`buildAho(patterns)` returns a `Result[AhoCorasick, AhoError]` (an empty pattern is refused). `findAll(text)` returns `Match(start, pattern)` values ascending by (start, pattern index); `countAll(text)` returns one count per pattern. The automaton is a plain value, so searching never changes it. Module: `src/nimcs/algo/aho_corasick.nim`.

```nim
import nimcs/fp/result
import nimcs/algo/aho_corasick

let built = buildAho(@["he", "she", "his", "hers"])
doAssert built.isOk
let found = built.value.findAll("ushers")
doAssert found.len == 3
doAssert found[0] == Match(start: 1, pattern: 1)   # "she"
doAssert found[1] == Match(start: 2, pattern: 0)   # "he"
doAssert found[2] == Match(start: 2, pattern: 3)   # "hers"
```

## Laws and invariants
- `findAll` returns exactly the (start, pattern index) pairs of the naive quadratic search (STR-AHOCORASICK-01).
- Overlapping and nested patterns are all reported; matches ascend and spell their pattern (STR-AHOCORASICK-02).
- With one pattern the starts equal `kmpFindAll` (STR-AHOCORASICK-03).
- `countAll` agrees with the number of matches per pattern (STR-AHOCORASICK-04).
- An empty pattern is refused; an empty pattern list builds (STR-AHOCORASICK-05).
- Duplicate patterns are reported under each index (STR-AHOCORASICK-06).
- Searching is repeatable on the same or a rebuilt automaton (STR-AHOCORASICK-07).

## Complexity
Build O(total pattern length * 256) time and space in this reference (a full 256-way table per trie node; a map per node would trade space for lookup time). Search O(text.len + matches) plus the sort of the matches, O(m log m) for m matches. The automaton is never modified by a search.

## Pitfalls
Reporting only the longest pattern that ends at a position loses the shorter patterns that are its suffixes (`"he"` inside `"she"`):

```nim bad
# keeps only the node's own pattern, not those reached through failure links
for index in ownPatterns[node]:
  result.add Match(start: i + 1 - lens[index], pattern: index)
```

Fix: merge the failure node's outputs into each node while building (breadth first, so the failure node is already complete), as `buildAho` does. A second trap is computing the start as `i - len`; the end index `i` is inclusive, so the start is `i + 1 - len`.
